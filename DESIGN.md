# DESIGN.md

## Position

Интерфейс похож на личный лист рассуждений: холодная бумага, тёмные чернила, один насыщенный синий для выбранного ответа и линии профиля. Вопрос занимает экран и не конкурирует с навигацией. На результате лист становится картой: двенадцать осей соединяются в единственный запоминающийся контур.

## Why this is not an Anthropic cliché

- **Not Cream & Terracotta** because: поверхность холодно-синяя, акцент — цвет чернил; нет тёплой галерейной палитры и декоративного курсивного серифа.
- **Not Cyber-Dark** because: светлая читаемая поверхность нужна для длинного теста на телефоне; нет неона, терминальной типографики и псевдостатусов.
- **Not Broadsheet / Newsprint** because: это последовательный интерактивный тест с одной колонкой и крупными касаниями, а не плотная многостолбцовая публикация; правила и номера используются только для состояния прохождения.

## Density

Regular, шаг 4 px. На телефоне одна колонка, минимум 44 px для касания.

## Motion philosophy

Движение разрешено только когда показывает выбранный ответ, переход к следующему вопросу или построение итогового контура.

Allowed: заполнение прогресса, короткая смена вопроса, однократное построение карты результата.

Forbidden: скролл-анимации, бесконечные циклы, пульсации, hover-scale, декоративные появления блоков.

## Signature (exactly one)

Name: Контур карты мышления.

What it is: двенадцатиосевая диаграмма, построенная из фактических результатов и подписанная названиями шкал.

Why a competitor cannot steal it without stealing the product: число осей, их смысл и форма контура напрямую происходят из двенадцати шкал этого теста.

What stays quiet so this can be loud: одноцветные контролы, отсутствие иллюстраций, теней, декоративных иконок и дополнительных акцентов.

## Layout concept

Один лист меняет назначение: вводная → один вопрос → персональный отчёт. На широком экране результат раскладывается на карту и текст; на телефоне карта идёт перед разбором.

```
+------------------------------------------+
| Карта мышления                  01 / 61  |
| ======================================== |
|                                          |
| Один вопрос, занимающий центр листа      |
| [ ответ ]                                |
| [ ответ ]                                |
| [ ответ ]                                |
|                              [ Дальше ]  |
+------------------------------------------+

+------------------------------------------+
| Результат                                |
| [ 12-осевая карта ]  [ связный разбор ]  |
| [ шкалы и философские выборы ниже ]      |
+------------------------------------------+
```

## Content model

```
BLOCK: Вход
JOB: объяснить границы теста и начать/продолжить
SHAPE: короткий тезис, четыре факта одной строкой, одна инструкция, действие
NOT: hero + карточки преимуществ + два конкурирующих CTA
```

```
BLOCK: Прохождение
JOB: ответить на один пункт и видеть реальный прогресс
SHAPE: один вопрос, группа крупных вариантов или подписанное поле, номер и прогресс
NOT: опросник-таблица, карусель-карточка, постоянные подсказки под контролами
```

```
BLOCK: Результат
JOB: увидеть рисунок мышления и прочитать связный персональный разбор
SHAPE: 12-осевая карта, 4–6 выводов с основаниями, шкалы, дилеммы, собственные ответы
NOT: общий балл, сухая статистика, «тип личности», сетка одинаковых карточек
```

## Uniqueness tests

1. Swap logo, name, two accent colors. Still plausible for another company?
   - Answer: нет; двенадцатиосевой контур, язык шкал и последовательность «самоописание → дилемма → рефлексия» принадлежат этому тесту.
   - If yes, what we change before code: не требуется.
2. Would this palette / pairing / layout appear for a generic "modern SaaS" prompt?
   - Answer: нет; это один рабочий лист без навигационного chrome, карточек преимуществ и SaaS-композиции.
   - If yes, what we change before code: не требуется.
