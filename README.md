# Карта мышления

Статический мобильный тест на русском языке. Он работает без аккаунта, базы данных и API: ответы сохраняются только в `localStorage` браузера, а связный итоговый разбор строится локально по сочетаниям шкал, философских выборов и структуре свободных ответов.

## Что внутри

- 48 утверждений по 12 шкалам;
- 8 философских дилемм;
- 5 необязательных свободных ответов;
- сохранение и продолжение на том же устройстве;
- двенадцатиосевая карта и локальный содержательный разбор;
- экспорт отчёта в текст и JSON;
- адаптация под экран около 390 px, клавиатуру и `prefers-reduced-motion`.

## Запуск

Сайт состоит из `index.html` и `_headers`. Для локальной проверки достаточно отдать корневую папку любым статическим HTTP-сервером.

## Публикация

Корень проекта является готовой директорией статических файлов. При создании Cloudflare Pages-проекта не нужны команда сборки и каталог сборки: публикуется корень репозитория.

Wrangler для этого проекта не требуется.

## Граница метода

Это авторский исследовательский тест, не клиническая психодиагностика и не валидированный личностный опросник.
